# Harry-Potter-Retrieval-Augmented-QA-Chatbot-using-LangChain
Harry Potter Retrieval-Augmented Question Answering Chatbot Using LangChain, FAISS, and Hugging Face Model. The embedding model used is sentence-transformers/all-MiniLM-L6-v2 from the sentence-transformers library.
